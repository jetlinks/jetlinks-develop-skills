# 业务语义与企业页面

菜单、详情分区或跨业务表达尚不清楚时读取。按当前任务识别对象、事实、关系和动作，无需为普通页面创建本体模型；文献及适用边界见 [设计依据](interaction-design-foundations.md)。本文决定内容含义，编辑行为归 [连续交互](task-interaction-rules.md)，组件与布局归 [场景组件](component-reuse-patterns.md)。

## 从业务含义组织阅读

| 含义 | 用户应能理解及执行的事 |
| --- | --- |
| 身份与识别上下文 | 业务名称为主，类型、位置及必要编号辅助识别；技术 ID 次级、按需复制，不占据主标题 |
| 自身属性 | 值、单位和枚举含义清楚，按业务概念分组；阅读为主时原位维护，持续录入保留输入 |
| 引用与关系 | 呈现有方向的业务名称及目标，如“所在空间”“负责人员”，可就近进入并返回；不只显示外键，不把普通关联画成因果链 |
| 观测与查询事实 | 值与时点关联，必要时显示来源、质量和适用范围；只读事实与可编辑配置分开，未知、读取失败不显示为正常 0 |
| 业务状态与动作 | 状态解释当前处境，动作使用动宾名且靠近目标；不能以状态下拉绕过合法动作，命令受理不等于实际完成 |
| 规则与过程 | 输入、条件、结果 / 动作说明决策；过程表达真实顺序和执行记录。定义、当前草稿、已发布版本与一次运行有不同身份 |
| 设置与生效 | 用户知道改谁的设置、继承或覆盖什么、何时生效；局部接受、持久化、运行应用按真实契约区分 |

分区围绕“共同回答一个问题、共同维护或影响同一决策”，不用 API、实体字段顺序或相同字段数划分。名称 / 编号可属于身份，安装资料属于维护，温度 / 时间属于观测，负责人属于关联，停机属于动作；不默认平铺在“基本信息”表单或平均分成同形卡片。

## 菜单与上下文导航

- 全局入口承载稳定的业务对象集合、角色任务和独立的定义 / 设置目的地；对象动作放当前上下文，不按数据库表、部门或微服务目录机械生成菜单。
- “我的待办 / 异常处置”与“全部对象”服务不同任务；规则 / 模板定义与运行记录也应能区分，不要求因此增加固定数量的菜单。
- 同一对象保持规范详情入口，可从集合、关联和待办到达；带入对象及任务信号，返回恢复筛选、分页与定位。当前对象的关系不需要逐个变成全局菜单。

## 常见任务的结构选择

| 场景 | 左侧何时有用 | 主区与动作 |
| --- | --- | --- |
| 普通台账 | 稳定空间 / 分类、常用视图等确能缩小集合时使用；与主筛选共用条件语义 | 表格适合列对比，摘要列表适合逐项理解，卡片适合图片 / 空间识别。身份列、关键状态和任务相关业务值优先；名称进入、复选框选择、行内动作各自明确 |
| 多业务联动 / 处置 | 待办状态、任务队列或对象导航服务当前角色时使用 | 当前事项、关联对象、证据和下一动作相连；参数就近展开，回执指向原业务记录。需要探索多跳影响才用关系图，不铺开所有系统字段 |
| 规则 / 流程 | 定义类型、目录或真实步骤有导航价值时使用 | 简单条件用业务语句，公式用统一编辑器；多条件比较可用决策表，真实过程依赖才用流程 / 向导。样本与对应节点结果相连，定义图不冒充实际执行路径 |
| 设置 / 配置 | 稳定设置分组对应内容目的地时使用，不能伪装成查询条件 | 展示当前值、来源与影响，关联输入就近出现；相关字段按最小合理边界提交。个人展示偏好、对象配置与共享业务定义分开，不将所有设置自动保存 |

左栏随任务改变，不把空间树、状态列表和设置目录统一成同一套“全部”筛选。主区已有工具栏与结果时不为名称 / 数量再加无独立用途的标题带；内容少允许合理留白，不能靠重复统计或教程填满。

## 详情与读写一体

- 首屏先回答“是谁、现在怎样、接下来做什么”，再按业务问题组织属性、关系、观测、配置及记录。分区名使用用户语言，不强制所有详情有相同 Tab。
- 轻量字段原位编辑，紧密关联配置分区编辑；停用、发布、受理等仍是业务动作。原位接受到草稿不自动等于持久化，查看关联对象不触发当前内容编辑。
- 相关内容需要并行核对时才左右分区；上下阅读更自然时使用单主区。图标、卡片、色彩服务身份、分组和状态，不以数量证明现代化。

例如设备详情可展示“身份与运行状态 → 安装资料及负责人 → 最新观测 → 关联异常”，处置详情可展示“当前事项 → 证据与关联目标 → 办理动作与回执 → 实际过程”。它们是任务组合示意，不要求每页具备全部区块或新增后端能力。

对象引用、语义和动作沿来源公共契约，不为页面便利引入 ontology 依赖、第二份业务事实或平行权限。平台指标、告警和通知复用按 [boundary](../../jetlinks-boundary/references/platform-capability-reuse-rules.md)；只呈现已装配且授权可用的能力，示例数据不证明生产接通。
