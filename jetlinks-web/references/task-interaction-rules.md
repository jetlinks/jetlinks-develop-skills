# 连续任务与读写交互

配置、设计器、持续维护，或交互分散、偏离已接受方案时读取。密集录入与列比较可以保留表单 / 表格；“去表单”不是独立目标。

## 保留任务联系

- 用户能辨认当前对象、作用范围和关键内容；选择项与设置对应，切换不误改其他对象。
- 按实际需要连接查找 / 新建、修改、核对与提交，不按后端接口拆成互不接续的页面，也不为不存在的阶段造入口。
- 主区承载正在处理的内容，参数与证据按需要就近展开。预览可用任务草稿，不为预览持久化无效对象。
- 联动配置保留共同草稿与提交范围；局部接受不自动等于持久化。字段独立保存仅在接口与业务不变量允许时使用，编辑层级见 [读写组合](component-reuse-patterns.md#读写一体与编辑层级)。
- 选择、折叠、调整宽度与返回保留任务需要的草稿和定位；离开未提交对象沿既有保留 / 丢弃策略处理，不为简单任务新建全局草稿系统。取消回到正确基线，失败保留可修正输入。

## 表达与输入

- 条件、时间、单位和动作适合业务语句或公式时，就近组合可编辑片段，使用完整 i18n 消息，不按中文词序拼字符串。长文本、凭据、密集录入及比较任务保留适用字段布局，不为每组设置编写叙述句或同义解释。
- 选择、icon / 名称 / 说明、选项宿主与按钮语义统一按 [动作与选择](action-and-selection-rules.md)。只读内容保持正常阅读，编辑入口可发现，不将禁用控件铺成详情。
- 能从真实契约确定的默认值、类型或来源不重复询问；必要识别结果可核对 / 更改，不静默改变已保存含义。
- 标签、帮助与格式约束在需要时可见；校验在字段已交互、局部提交等可纠正时点出现，不在首次打开或正常未完成输入时铺满错误。规则来源归 [数据契约](quality-and-type-rules.md#类型与数据契约)。
- Enter / Esc / blur、输入法与复合浮层沿实际编辑器契约，不强加统一自动保存，也不为每个字段重复保存按钮。

## 修改、试验与应用

- 输入、选择和展开及时反馈，耗时计算与远程请求单独控频；不延迟真实输入掩盖性能问题。保持焦点与布局稳定，动效解释变化并尊重减少动态效果设置。
- 样本结果对应对象、输入及配置；配置改变后保留旧结果时须可辨认。错误指向相应字段、节点或阶段，提交与迟到结果按 [状态管理](state-management-rules.md) 处理。
- 保存、试算和发布按各自真实契约反馈，受理不冒充完成；试验说明必要影响，不假定“测试”无副作用。
- 提示对应实际事件与当前对象：有修改、等待、错误或生效差异时给出必要反馈；无修改、正常只读或编辑入口隐藏不默认各占常驻说明。短暂确认不累积成横幅，未解决错误、待办及必要运行状态仍可见；沿已有反馈机制，不另建定时清除框架。
- 公式编辑 / 查看使用统一 MathLive 与结构化表达式，执行与指标选型见 [计算复用](../../jetlinks-boundary/references/platform-capability-reuse-rules.md#计算先选结果能力再选公式表达)，不另写解析器或前端执行权威。

阶段末走通本次改变的任务路径及必要取消 / 失败恢复，核对只读、长内容或窄容器等实际受影响状态。原型进入平台还需 [宿主核对](component-reuse-patterns.md#宿主与自适应)，独立截图不证明正式页面协调或用户效率提升。
