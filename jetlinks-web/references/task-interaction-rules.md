# 连续任务与读写交互

配置、设计器、持续阅读维护，或出现表单感重、交互分散、偏离已接受原型时读取。普通局部修改直接沿当前契约，密集录入与列对比可保留表单 / 表格；不把“去表单”当独立目标。

## 从当前设计提炼结构

| 场景 | 可借鉴的结构 | 不应推导成 |
| --- | --- | --- |
| 表单设计器 | 实际内容可见，选中内容后修改相关属性，同一份定义预览填写与只读效果 | 所有业务必须有画布或重新发明表单 schema |
| 数采工作区 | 当前对象 / 点位、设置与试读结果相连，连接与点位的作用范围清楚 | 原型试采已接通真实采集，或试读必定没有副作用 |
| 指标模板 | 输入、计算与输出关系可见，关联设置随选择展开，样本与节点结果对应 | 简单规则也需要完整依赖图或复制指标引擎 |
| 属性预处理 | 当前属性的处理语句 / 公式连续表达，样本按实际顺序说明阶段结果 | 当前消息能够读取任意属性、历史或外部数据 |

共性是内容可见、操作跟随对象、修改与结果相连；布局形态仍由内容排布、主从关系或依赖结构决定。真实能力与路径按 [示例定位](example-locations.md) 核验，不将原型候选当目标版本的公共 API。

## 一个任务保持一条完整路径

- 沿“找到 / 添加对象 → 修改 → 核对结果 → 提交 / 应用”组织真实需要的阶段，不为没有的阶段造入口。同一任务不按后端接口拆成互不相通的 Tab 或弹窗。
- 主区呈现正在处理的内容；参数就近展开，保留对象、位置与关系锚点。新建激活关键输入，成功后接续当前对象；不为了预览创建不能合法保存的半成品。
- 联动配置共享任务草稿，局部编辑接受与整组提交分开；字段独立保存只有真实接口和不变量允许时使用。复用组件的 Enter / Esc / blur、输入法与浮层语义，不给所有控件强加自动保存或保存按钮。
- 选择、折叠、切换视图和调整宽度不丢草稿或定位；取消恢复正确基线，失败保留可修正输入。离开未提交对象沿现有策略处理，不为简单任务新建全局草稿系统；异步归属与清理按 [状态规则](state-management-rules.md)。
- 只读仍是正常阅读内容，不渲染成整页灰色禁用控件。编辑入口可发现，键盘 / 触屏可达；不能仅靠 hover、去边框或移除标签制造轻量感。

## 让表达接近用户意图

- 条件、时间、单位和动作能形成完整语义时，就近组成业务语句或公式，如“温度超过 80 ℃，持续 5 分钟后触发告警”；使用可编辑片段和完整 i18n 消息，不拼接依赖中文词序的字符串。长文本、凭据和密集录入仍用适合的输入布局。
- 少量互斥模式可直接呈现为单选 / 分段，候选多时支持搜索，复杂对象选择带必要上下文；不能将所有意图都塞进单调下拉，也不因现代化把所有下拉改成卡片。
- 图标帮助区分对象、类型和动作，名称承担主要含义，短说明只补用途差异 / 影响；复用 `SelectOption` 等内容组件，展开态可多一层信息，选中态保持紧凑。简单枚举可只用文字，不强造装饰图标、随机颜色或大行高。
- 选项内容只呈现，选择、焦点、搜索和禁用由宿主承担；不在普通 listbox 选项中嵌套独立按钮 / 链接。身份值、显示名与说明分开，后端枚举仍沿 [枚举契约](enum-rendering-rules.md)。
- 能由真实契约可靠确定的默认值、类型、来源或单位不重复询问；展示必要识别结果，歧义时允许核对 / 更改，不静默改变已保存含义。

## 修改、试验与应用的反馈

- 输入、选择和展开及时给本地反馈，请求与耗时计算单独控频，不延迟真实输入以掩盖性能问题。保留焦点和布局位置，动效只解释变化并尊重减少动态效果设置。
- 样本结果关联对象、输入与配置版本；配置改变后旧结果可保留但须可辨认，乱序返回不能覆盖当前结果。错误指向对应字段、节点或处理阶段，不只弹一个全局失败提示。
- 明确草稿、已保存与已生效的真实差别；现有成功回执不自动等于运行完成。试算 / 试读 / 发布按各自执行契约说明必要影响，不假定“测试”均无副作用。
- 公式编辑 / 查看复用统一 MathLive 与结构化表达式，试算沿同一运算语义；指标配置与普通公式求值的职责按 [计算复用](../../jetlinks-boundary/references/platform-capability-reuse-rules.md#计算先选结果能力再选公式表达)，不另写解析器或前端执行权威。

阶段验收走通同一对象的修改、取消、失败恢复、结果核对及提交，并检查只读、长内容和窄容器。原型进入平台还需 [宿主核对](component-reuse-patterns.md#宿主与自适应)，不能以独立预览截图证明正式页面已协调；没有用户研究时不宣称效率提升已获证明。
