# JetLinks Web Business UI Example Rules

参考用于补充实现模式，不替代业务判断。示例统一放在 core，定位见 [Core 自包含场景](example-locations.md)。

## 参考顺序

1. 用户在当前任务已接受的原型、参考与操作路径。
2. 当前 `cloud.jetlinks/runtime-ui` 同类功能的公开组件、布局与接线事实，以及 `jetlinks-web-core/src/views/interaction-examples/` 对应场景。核对真实用法，示例保持 core 自包含，不复制业务模块私有实现。
3. 适用的设计系统实践与 [交互设计依据](interaction-design-foundations.md)。

平台统一 token、组件、主题与语义反馈。示例不证明业务接口、权限或计算能力存在；用户已接受的路径不被旧页流程覆盖，真实契约冲突须说明并适配。

视觉一致性同时包含真实宿主的导航 / 内容面板、主题 Provider、组件变体及内容密度，详见 [宿主契约](shared-interaction-contracts.md#原型进入平台统一宿主契约)。保留已接受的业务任务与操作顺序，按宿主已有能力调整外层承载；不要将示例工具条、独立预览留白或面板层级整体搬入生产页面。

实现示例使用目标版本的真实 Vue 组件及实际 props、slots、事件；列表、布局、状态和编辑优先沿当前运行时功能已使用的组件。独立 Vite 的 HTML 文件只是挂载入口，不能用手写静态 HTML / CSS 仿造平台组件来充当实现或验证。示例数据可以本地化，组件行为不能假接线。

## 按任务选择借鉴内容

| 当前任务 | 借鉴的 Core 场景 | 保留的业务边界 |
| --- | --- | --- |
| 独立创建与信息维护 | 同一工作区新建：直接输入、图标选择实际内容、常用值与自定义、整组校验后打开该对象 | 创建前提、必填约束、服务端提交与错误；持续录入所需的直接输入 |
| 持续阅读与维护对象 | 对象详情：名称与状态优先、独立信息原位编辑、信号直达对应规则、应用结果返回详情 | 权限、是否允许单项提交、状态转移与关联数据 |
| 连续修改关联参数 | 配置工作区：选择、换算、条件、样本验证、应用；按对象和信号保留草稿 | 规则语义、执行器、插件联动、整组校验与应用 |
| 左右分区或窄容器适配 | 容器布局与分界线：宽度约束、按任务重排、状态保留 | 内容顺序、主区最小宽度与实际设备限制 |
| 左分区与右集合 | 分区与通用条件共用查询，右侧用平台列表；进入详情、关联对象再返回仍保留筛选、分页与焦点 | 分区是分类、任务状态还是独立设置页；计数范围、批量边界与真实查询契约 |

表单设计器、数采、指标模板与属性预处理提炼出的共性见 [任务连续交互](task-interaction-rules.md#从已有设计提炼的共同结构)。这些经验保留各自的业务表达，不要求统一成相同栏数、画布或 schema。

## 不应照搬

- 示例字段、样例数据、业务接口、权限码或局部内部导入路径。
- 任务不需要的统计卡、趋势图、快捷入口、流程步骤或同质 Tab。
- 样例中的本地保存 / 执行方式；生产必须换入自己的真实契约。
- 把独立字段的失焦提交推广到联动配置，或为统一体验创建万能页面壳。

例如，对象创建与后续维护可以共用内容布局，值就地激活编辑，必填与错误仍清楚可见；大量首次录入可以直接保留输入。连续规则适合业务语句与关联结果，不能将所有片段拆成各自保存的表单。密集列对比可以使用表格，不为了复用配置场景而改为画布。

完成时说明借鉴了什么交互行为，以及真实数据、提交和权限的适配；只涉及局部样式或文案时不重新做整页分析。
