# JetLinks 条件筛选与表达式搜索

用于组合查询、Token 化条件、远程选项、路由回显及快捷筛选联动。基础组件与编码器名称均按目标版本的 [事实源](component-source-rules.md) 核验，不从此文推断完整 API。

## 选型与条件 owner

- 目标项目已有 ConditionFilter 及编解码链时，业务列表的通用条件搜索默认优先复用，通过字段 schema 表达名称、状态等条件；不先拼一个搜索框和多个独立 Select，再补第二套条件状态。窄改稳定旧页可沿用 ProSearch；没有组合条件、统一路由回显或选项加载等需求的少量固定筛选，也可使用适用的既有轻量方案。
- 旧表格外观不决定筛选协议。外观要求与所需条件能力并存时，沿公开组合调整，不能因“保持旧风格”丢失查询语义，也不为窄改强迁整页。
- 已生效条件有一个权威来源；允许编辑草稿、UI 投影、terms / where 和路由编码等不同表示，通过统一转换保持一致，不要求同一对象实例，也不维护各自独立的生效状态。
- 组件拥有条件交互，业务提供字段语义与选项源；先用公开 schema / 插槽，不在通用组件硬编码业务 API、字段或场景分支。确认公共缺陷回 [组件 owner](../../jetlinks-conventions/references/root-cause-and-no-hack-rules.md#通用组件缺陷的闭环)，真实业务差异可使用正式扩展点。

分组／树导航内的定位与右侧业务条件搜索作用范围不同，不统一套 ConditionFilter。少量且可完整扫视的导航项不常驻搜索；集合较大或难以定位时才在导航上下文提供搜索，沿公开头部能力组合，避免额外分出搜索卡片或横带。完整本地集合可本地过滤，不完整集合应查询完整来源，不能只过滤已加载项冒充完整搜索。

## 字段、操作符与值

字段定义表达名称、查询列、类型、适用条件及值来源；可以使用当前组件的推导 / 默认值，不机械要求每项都显式配置。新接入优先当前 fields schema，旧 columns 接法按目标版本兼容契约处理。

| 值语义 | 选择依据 |
| --- | --- |
| 文本、数值、布尔 | 通用值编辑器；条件依业务语义选等于、包含、大小等，不能只按 TS 类型推定 |
| 日期 / 时间与范围 | 通用时间或范围能力，沿接口的时区、边界和精度；不按字段业务名复制面板 |
| 枚举、引用与树节点 | 通用选项 / 对象编辑器；值与名称分离，选择规模和完整性决定本地或远程加载 |
| 无值条件 | isnull / notnull 等不打开值面板，确认与搜索节奏沿组件契约；接口占位要求在转换层统一处理 |
| 嵌套、关联或数组 | 先核验字段映射与标准查询语义；UI 路径不自动等于后端查询列，不把复杂关联降成普通字符串 |

`rename`、`handleParamsItem` 等公开入口用于必要的列 / 值 / 条件映射。字段编辑确有独立业务语义时扩展值编辑器，仍接入共同条件模型；不复制整套搜索壳。单选、多选、包含任一 / 全部及否定沿查询契约，不能仅凭选择器外观默认改成 in。

## 连续编辑与确认

- 标准条件在输入区直接可见，Token 可重新编辑，不给整个筛选框再套一层查看 / 编辑模式。值选择可使用适用弹层或专用编辑器，不强迫复杂对象选择塞进单行。
- 字段匹配、候选生成、操作符切换、清空与无值条件沿既有交互；不要在业务页重写文本解析、键盘或内部光标逻辑。
- 完整有效值按组件契约确认；未完成输入、无效值和浮层切换不能因 blur 被误提交或丢弃。输入法组合期间不提交。
- Enter 接受候选 / 当前值，Esc 关闭或取消并恢复焦点；Tab 保留可退出的焦点顺序，条件修改与删除可键盘访问。
- 操作符和值各有 owner；不在多个位置放竞争的操作符入口。切换字段或条件按语义保留可复用输入，不默默提交旧字段的无效值。
- 已确认条件、手动搜索和自动搜索由既有链路协调，避免在 change、watch 和路由回调各触发一次请求。远程输入控频和旧结果隔离按 [状态管理](state-management-rules.md)，不逐页叠加防抖。

## 选项来源与标签恢复

- 完整且规模有界的集合可本地过滤与恢复名称；分页、不完整或较大集合使用远程过滤 / 分页，不能只筛当前页冒充完整搜索。
- 选中值优先由既有完整来源解析；缺少标签时使用 loadSelectedOptions 等按值补查能力，不为已能解析的小集合加回查接口。失效、删除或不可见目标按当前契约表达，不伪造名称。
- 标签、路径与补充信息来自同一选项语义，查询仍提交真实值；树选择保留必要层级，枚举按 [EnumDict 契约](enum-rendering-rules.md) 处理。
- 名称、icon 和次级说明按 [动作与选择](action-and-selection-rules.md#触发入口与候选内容) 组合；不在普通 listbox 选项里嵌套独立按钮 / 链接。
- 自定义值编辑器从传入值恢复选择，按公开 update / submit 契约交回结果；浮层重建或卸载后不让迟到回填污染当前编辑。

## 快捷筛选、范围与路由

- 快捷项与已保存搜索通过标准模型更新用户条件，不维护第二份查询真值。当前对象、路由或授权限定的固定范围由宿主按契约合并，不混成用户可删除的条件；前端范围不替代服务端统一授权。
- 按任务区分快捷项与独立范围的替换 / 合并关系，不因左侧有导航就清空其他有效条件；页面请求统一消费最终查询。
- q 编解码、字段别名、名称回显与请求转换沿同一字段语义，复用已有编码器及版本兼容；不手拼 terms JSON 或另造 URL 协议。
- 路由恢复不重复叠条件或触发多轮搜索；中文、范围、0 / false、分组等按实际契约保留。转换层已有通配符转义、日期处理等能力时不在页面再处理一次。

阶段末按变化验证条件输出及清空、编辑确认 / 取消、必要的路由往返、远程候选和标签恢复。重点检查重复请求、漏搜、丢条件及提交值错误，不要求每次改字段都穷举所有编辑器。
