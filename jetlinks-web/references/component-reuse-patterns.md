# JetLinks 场景组件与整页约定

用于列表、详情、配置和分区布局的组件组合。组件名是检索候选；基础层和项目层分别按 [事实源](component-source-rules.md) 验证，不从矩阵推断目标版本支持。

## 读写一体与编辑层级

按用户完成任务的最小合理范围选择：

| 范围 | 交互 | 候选 |
| --- | --- | --- |
| 名称、标签、说明、备注、单项开关 | 原位查看 / 编辑及就近反馈，不默认完整弹窗 | InputEditable、Editable、FormItemEditable、标签组件 |
| 语义关联的一组配置 | 分区局部编辑，保存 / 取消就近 | SectionCard、KvGrid、StickyActionBar |
| 强依赖、多字段整体校验 | 连续配置区、抽屉或独立页面 | EditDialog、JlDrawerShell、现有配置编辑器 |
| 确有阶段依赖的开通 / 发布 | 分步流及阶段结果 | 平台已有步骤 / 向导能力 |

保存、取消、失焦、Enter / Esc、焦点恢复与失败回显按目标组件及字段类型契约，不为每个页面再写一套编辑器。原位编辑不等于所有变更立即生效，保留草稿和提交语义。

目标 core 已有 `InlineEditForm` 时核验详情 / 首次填写、已保存基线、异步提交与自定义编辑器契约；选项、失焦、复合浮层沿其真实行为。联动配置不能机械逐字段持久化；也不把一套 schema 强套所有阅读页面，已有 `Editable` 等局部能力仍按任务使用。

## 详情与主从布局

- 对象摘要呈现身份、关键状态、主要动作和必要说明；事实、业务关系、配置、操作结果与历史按语义分区，不平均平铺字段。
- 左侧内容对应范围 / 对象导航或步骤；右侧承载当前任务。导航、搜索、折叠入口就近组织，复用现有可折叠 / 自适应布局。
- 对照字段适合表格，复杂对象识别适合摘要列表或卡片，关联网络和时序分别使用关系 / 时间表达；不强制所有页面表格化。
- 反向引用、关联记录有真实数据来源与权限，按用户任务决定位置和空态；有用的零关联提示或新增入口不因“空时隐藏”规则被删除。
- 摘要与主内容首屏有清晰层级，避免重复标题、大段解释、装饰 hero 或无用指标挤占操作空间。关键状态和主动作可以共存，不靠固定区块数量决定合理性。

## 平台组件组合

| 语义 | 候选 |
| --- | --- |
| 页壳与头部 | FullPage、PageHead |
| 范围导航 / 列表 | 平台侧栏 / 树 / 分区组件，j-pro-table、VirtualScroll、摘要卡片 |
| 条件筛选与快捷联动 | ConditionFilter 及字段、选项、回显与编码契约 |
| 对象摘要 / 事实分区 | EntityCard、CardBox、SectionCard、KvGrid、TabsCard |
| 状态 / 分类 / 图标选项 | MetaChip、ChipGroup、AppTag、平台 icon 与选择器 |
| 资源选择 | MarketplaceResourcePicker、CardSelect |
| 抽屉与固定操作 | JlDrawerShell、StickyActionBar |

先组合已有组件，不造同形控件。确认公共组件缺陷时，在 [组件 owner 修复并提交 PR](../../jetlinks-conventions/references/root-cause-and-no-hack-rules.md#通用组件缺陷的闭环)，不能用业务页 wrapper 或深层覆盖绕过。

## 宿主与自适应

- 明确宿主与内容各自提供的页头、导航、面板、内边距、高度和滚动；独立预览的演示工具不复制进成品。复用同一组件不证明已接入相同主题，浮层也须处于正确 Provider、样式处理及 token 环境。
- 按整个内容页调整共同对齐线、固定导航与伸缩主区、组内 / 组间间距和阅读宽度。长文本限制阅读行长，表格按比较任务利用宽度；不靠放大标题、padding 或重复卡片填空。
- 左栏语义随业务变化，折叠只保留一处明确入口；有搜索时可与其置于同一工具栏，无搜索时沿分区标题。位置由可发现性与现有组件契约决定，不能以 hover 独占入口或在多个位置重复按钮。
- 根据实际容器而非仅窗口断点重排，包含平台侧栏与面板展开后的宽度变化；保留草稿、选择和阅读顺序，固定动作区不能遮住错误或键盘焦点。拖动尺寸有适用的键盘及单指针替代。
- 受约束工作区由宿主提供高度，列内滚动保持主动作可达，表格横滚限定在表内；长阅读页可自然流动，不给所有组件套固定视口高度、强制等高或独立滚动。

整页变化在正式壳层与相邻同类页面中核对标题 / 动作、浮层、长内容和窄容器。独立预览只能证明相应组合与本地交互，不能把“用了真实组件”当成嵌入效果已经验收。

## 视觉、动作与文案

- 使用当前设计系统的间距、字体、状态色、边界和 z-index。状态已有 badge / pill 时，不再叠多套彩条和强底色制造噪声。
- 主要动作、分区动作与行操作分别靠近其对象；固定条或 FAB 只在任务需要且平台已有契约时使用，不规定每页必须有浮动按钮，不复制未核验的偏移数字。
- 下拉和菜单选项用有含义的 icon、短标签和必要补充说明，保持可访问名称；不机械给所有选项加装饰 icon。
- 技术配置 / 接入 / 排障可展示用户需要的字段 key、API、Topic 或命令 ID；原型说明、TODO、无关内部标识不进入正式页面。
- 文案、枚举、条件筛选和异步状态分别遵循其 owner 规则；不为选页面模版额外安排一次确认，也不默认普通列表 + 完整编辑表单。
