# 页面区块的用途与优先级

设计新增统计、图表、概览和快捷区时读取。判断信息是否支持当前任务，不为每个标题、字段、错误或说明建立准入表。

## 选择内容

确认谁使用、帮助什么判断、数据来源及呈现位置；有动作时说明如何承接。身份、事实、合规说明、必要帮助与状态反馈可以本身就是任务结果，不要求每块都有按钮或钻取。

| 内容 | 保留依据 | 常见误用 |
| --- | --- | --- |
| 统计 / KPI | 数据口径、权限、刷新和成本明确，支持风险 / 进度判断 | 无来源数字、把未知显示为 0、逐行补查大历史 |
| 趋势 / 分布 | 变化或分布是用户需要理解的结果 | 为填空添加假曲线，强加无用途钻取 |
| 快捷动作 | 能缩短高频或关键操作路径 | 无关低频入口抢占首屏 |
| 对象摘要 | 帮助定位对象与关键状态 | 重复大标题、平铺无重点字段 |
| 帮助 / 空态 | 解释用户当前输入、权限、配置或恢复方式 | 原型说明、TODO、开发过程进入正式 UI |

摘要可以有意重复少量关键事实，减少跨区寻找；不能只因下方也有相同字段就删除。无关联数据时，有意义的零关联提示与新增入口仍可保留。

## 布局取舍

优先身份、关键状态与当前动作，再按业务语义分组细节。左右区、卡片与留白表达关系和层级，不用固定统计卡数量或统一侧栏填满所有页面。

空间不足时调整密度、分区和渐进展开；空白本身不要求加数据。可选内容无法说明用途时删减或降到次级区域，必要业务事实不因缺少“下一动作”被删。

阶段末核对本次结构变化的用途及数据边界；不要求为普通字段、标题或提示另建准入材料。
