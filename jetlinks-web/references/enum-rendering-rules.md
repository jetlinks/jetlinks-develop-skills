# JetLinks 前端枚举契约

接口以 EnumDict / I18nEnumDict 对象返回枚举时，常见形态为 `{ value, text }`；以当前响应类型与实际接口为准，不从 Java 枚举名推定所有端点的序列化形态。

## 展示与提交

- 对象枚举展示 `text`，提交、比较、状态颜色、图标及权限逻辑使用 `value`。后端已提供 text 时不再维护平行翻译表；字段名、按钮和帮助等界面文案继续走前端 i18n。
- 选项可由 `{ value, text }` 转为 `{ value, label: text }`，编辑模型保存 value。接口未要求时不提交整份枚举对象。
- 字符串枚举沿已定义映射 / i18n 展示；只有真实接口允许混合版本时才归一形态，不让无关字段兼容所有可能类型。空值保持业务含义。
- 同一字段的标签、状态映射和转换保持明确 owner；多处重复时提炼适用 helper，单处直观取值不为统一而强建包装层。

## 消费处

| 位置 | 核对 |
| --- | --- |
| 表格、详情、卡片及导出 | 用户可读文本，颜色 / 动作使用真实 value，不出现 [object Object] |
| 编辑与选择 | label / value 分离，已保存值与选项来源匹配 |
| 条件筛选与路由 | 复用 [ConditionFilter](condition-filter-rules.md) 的选项、编码和标签恢复能力；URL 保存 value，不塞整份对象 |

禁止按 `text === '启用'` 判断稳定业务逻辑，或在多个页面各造一份后端文案映射。阶段末只验证本次受影响的显示、提交与回显形态，不为未出现的版本增加兼容分支。
