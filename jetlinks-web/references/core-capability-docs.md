# JetLinks Web Core 能力文档

本文件帮助定位目标 UI 工作区中的 `jetlinks-web-core/src` 能力。工作区可能是 `runtime-ui`、`ui` 或其他布局，以构建别名和当前入口为准。

## 按问题读取

已有组件 / 符号 / 导入锚点时直接核验；锚点不足且索引存在时，再读总索引或相关分类，不要求二者都读。

| 问题 | 候选索引 |
| --- | --- |
| 组件、页面壳、交互封装 | `src/components/README.md` |
| Hook、响应式逻辑、订阅 | `src/hooks/README.md` |
| 工具函数、运行时 | `src/utils/README.md` |
| Pinia、跨页面共享状态 | `src/store/README.md` |
| Core 页面或页面族 | `src/views/README.md` |

只打开当前候选的必要说明。索引不存在时从入口、源码与相邻用法定位，不为查文档安装模块或生成全量能力目录。

导出、插件注册、构建别名和实际依赖版本决定能否使用，见 [事实源](component-source-rules.md)。源码与文档冲突时核对目标版本，修正本任务涉及的过期说明。

## 维护能力文档

新增或实质改变公共能力时，原位更新已有分类索引和相关契约；复杂能力确有说明需要时再增单项文档。按实际需要说明适用语义、公开导入、关键参数 / 事件、状态 / 副作用、必要示例和限制，不机械填模板。

页面说明保留任务、入口、数据、权限和关键交互；不追加临时排查、阶段总结和测试流水。模块私有能力留本模块，跨模块稳定能力归其公共 owner。
