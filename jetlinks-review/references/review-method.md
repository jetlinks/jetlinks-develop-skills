# 证据与判定方法

## 从行为追到 owner

1. 先用业务语言说明本次操作应产生什么结果、谁能操作、什么必须保持不变；再定位读、写、执行、订阅或初始化的真实入口。HTTP、命令、事件、定时 Worker、回调与 UI 都可能走到不同路径。
2. 沿受影响路径检查谁拥有对象、数据、权限、事务、生命周期和副作用。已有框架保证直接引用；只有跨越新的信任 / 状态边界时才另判校验需求。
3. 按实际变化推演正常、失败 / 部分失败、重复 / 乱序 / 并发、取消 / 重启或升级中的相关情形。对疑点构造真实触发和合理反例，核实代码、配置、消费方与有效测试；不要求每次穷举全部维度。搜索命中本身不是发现。
4. 在共同根因层提出最小完整修复。若问题是依赖倒置，不能只搬类；若是 N+1，不能只提高并发；若是初始化耦合，不能只把客户 ID 改成常量。

## 跨场景的弱信号

先按 [场景链路](scenario-review-map.md) 检查结果和不变量；下面只帮助定位复杂度与职责问题，不能代替业务正确性审查。

| 信号 | 应补的证据 | 必须检查的反例 |
| --- | --- | --- |
| 组件职责混合、双向依赖 | 类型 owner、导入图、装配与变化原因；开关是否只掩盖错误落点 | 单一完整用例跨多个阶段不必拆成多个服务；函数抽取可能足够 |
| 重复校验或空值防御 | 可达调用方、同一主体 / 动作 / 对象、上游后置条件、重复 I/O | 独立入口、状态变化、模型出域、外部返回身份可能需要再校验 |
| 魔法值、隐式默认或策略叠加 | 取值依据、单位、配置来源、所有覆盖点、消费方 | 明确局部字面量和正式协议常量不必配置化 |
| 事务内 zip / flatMap | 真正订阅的 DB 操作、传播范围、连接 / 游标、结果是否消费完成 | 纯转换、独立远程读或不共享连接的事务外读取 |
| 并发读上限 | 数据规模、请求并发、池预算、嵌套 fan-out、批量替代与既有性能证据 | 小规模流沿默认值可能合理；不能把所有读取强制串行 |
| 权限或场景字段 | 统一 holder / dimension、资产类型与动作、字段真实领域含义 | 权限 Provider 内部维度，以及客户 / 组织等真实业务关系 |
| 特调、初始化绑定某业务 | 共享层的条件分支、业务消费者、启动副作用和升级行为 | 正式领域规则、显式安装业务数据、版本迁移及平台能力注册 |

这些是定点取证方向，不是每次必须填写的矩阵。规则细节回到 [技能入口的场景表](../SKILL.md#按需切片)。历史评审中的问句、建议或旧文件路径仍需当前代码验证，不能直接当未修复缺陷。

## 发现与疑点分开

可报告的发现需要包含：

- 精确定位到当前源码的位置或方案段落。
- 当前真实可达的触发；设计约束问题应说明违反的模块 / 数据归属契约。
- 实际影响：错误行为、安全风险、并发 / 资源失控，或具体维护成本。
- 通用修复方向与需要保留的边界。

推荐表达：“当……时，……路径会……，导致……；应在……owner 收敛 / 补齐……。”严重性按仓库约定和真实影响确定，未证实的性能问题不冒充已复现故障。

疑点缺少关键事实时继续窄范围核实；无法核实时单列限制，不给它伪造严重性或位置。用户只要求审查时，调查和必要的非破坏验证属于范围，修改实现、提交、发布仍按已有授权处理。

## 五类高频误行为

按实际后果而非关键词判断：过度设计核对当前消费者 / 不变量与抽象成本；过度校验核对同一 owner 是否已保证该约束；可读性检查业务阶段、命名和副作用能否追踪；魔法值核对语义、单位与策略依据；特调核对是否用样本 / 场景分支掩盖公共根因。合理抽象、独立安全边界、直观字面量与正式协议分派均需保留。

通用组件有缺陷却在调用方加 wrapper、深层覆盖或复制实现，不能只评价“当前页面能用”；应定位 owner 修复与上游 PR。纯审查输出该方向，不自动变更仓库。判断依据见 [职责规则](../../jetlinks-conventions/references/responsibility-and-generality-rules.md) 与 [文献边界](../../jetlinks-conventions/references/design-constraint-sources.md)。

## 阶段验证

- 先复用覆盖当前行为且源码相关输入未变的证据。只为未覆盖或失效部分选择最轻量的真实验证；有并发 / 事务风险时，纯 mock 无法证明连接与回滚语义。
- 权限删除与收敛同时核对合法允许和真实拒绝，部分更新核对历史值及实际生效变化，响应式核对取消 / 顺序 / 重订阅等本次影响的语义。
- 在连贯阶段完成后集中运行，不逐文件构建，不为无关代码补完整测试矩阵。只陈述实际执行或有效复用的结果。
