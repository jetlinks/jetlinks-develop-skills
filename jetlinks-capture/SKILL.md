# JetLinks Capture

负责稳定知识归属，不维护任务恢复状态，不在每次完成任务后自动创建总结。

## 工作方式

1. 判断结论是否稳定、非显然且能影响后续任务；没有新知识就结束，不强制给“是否沉淀”报告。
2. 优先原位更新已有权威来源。需要选择 knowledge、playbook 或技能时，查 [沉淀工作流](references/capture-workflow.md)，不另建平行知识库。
3. 用户已要求整理规范、维护技能或同步文档时直接完成。额外沉淀超出任务范围时，先给目标位置和简短草稿；只有真正缺少授权才询问。
4. 跨项目稳定规则可回写 `jetlinks-develop-skills`；准备或发布上游 PR 分别按已有授权和 [delivery](../jetlinks-delivery/SKILL.md) 处理，不因“可沉淀”自动发布。

只保留适用条件、结论、必要依据与例外；删除过时规则，不复制 diff、日志或会话摘要。事实与假设分开，运行态和测试证据留在各自载体。
